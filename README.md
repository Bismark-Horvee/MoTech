
    # MoTech

    MoTech is a responsive business landing page for a company offering managed IT, cybersecurity, 
    cloud, and web technology services.

    ## Features
    - Modern hero section and company branding
    - Services and company navigation links
    - Responsive layout for desktop and mobile devices
    - Contact and process-focused marketing content

    ## Tech Stack
    - HTML
    - CSS
    - JavaScript

    ## How to Run
    1. Open `index.html` in a browser, or
    2. Serve the project folder with a local web server.

    ## Project Notes
    This landing page is designed to present MoTech as a growing business technology partner 
    with clear service offerings and a polished brand identity.
